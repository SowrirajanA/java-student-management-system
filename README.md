# Student Management System

A simple console-based Java application to manage student records.

## Features

- Add Student
- View All Students
- Search Student by ID
- Delete Student by ID
- Menu-driven interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner Class

## Project Structure

```
StudentManagementSystem
│
├── Student.java
├── StudentManager.java
├── Main.java
└── README.md
```

## How to Run

1. Compile the Java files:

```bash
javac *.java
```

2. Run the application:

```bash
java Main
```

## Sample Menu

```
===== STUDENT MANAGEMENT SYSTEM =====
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit
```
